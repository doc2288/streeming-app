## 2024-06-14 - Icon-Only Button Accessibility Pattern
**Learning:** Found multiple icon-only buttons (like delete, go back, copy) that use hardcoded strings for `title` or lack translations, and many are missing explicit `aria-label`s which is problematic for screen readers. Using `title` provides visual tooltips, but `aria-label` is needed for consistent accessibility. There is a memory note about using dedicated translation keys for action buttons instead of reusing input placeholder translations (e.g., using `send` over `chatPlaceholder`). We need to implement proper accessibility for icon-only buttons using existing translations or newly added translation keys.
**Action:** When adding ARIA labels, use `aria-label={t('translation_key')}`. For buttons where only `title` exists but with hardcoded text (like "Копіювати", "Видалити стрім", "Reply"), migrate them to use translated strings for both `title` and `aria-label`. I will improve the accessibility of the `Copy` buttons in Dashboard and WatchPage, and the `Delete` buttons.
