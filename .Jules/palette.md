## 2026-05-16 - Accessibility pattern in icon buttons
**Learning:** Found a widespread pattern across UI components (e.g., `WatchPage`, `TopBar`, `Dashboard`) where icon-only action buttons rely entirely on `title` attributes for tooltips without an explicit `aria-label`, creating a disjointed experience for screen readers. Furthermore, these attributes are frequently hardcoded strings rather than utilizing the existing i18n localization system.
**Action:** When working on generic component UI, explicitly check for missing `aria-label` attributes on raw `<button>` elements, especially those containing only an `<svg>`. Always pair it with the `title` attribute for visual users and ensure both values are sourced from the global `t()` translation function to maintain strict accessibility and internationalization compliance.
