## 2024-06-08 - [Identify UX Improvement: ARIA labels on Icon Buttons]\n**Learning:** The copy buttons in `WatchPage.tsx` and `Dashboard.tsx` lack `aria-label` attributes and use hardcoded `title`s (e.g. 'Копіювати', 'Copy') rather than using the i18n system for internationalization.\n**Action:** Add `copy` key to i18n strings, replace hardcoded strings with `t('copy')` in `title` and `aria-label` properties for `.btn-copy` buttons to improve both accessibility and internationalization.
